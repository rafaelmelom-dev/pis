# Planejamento da disciplina

1. Determinação do Projeto
	* Título.
	* Introdução (Apresente Referências).
		1. **Contextualização do problema**:  Descreva o cenário atual: onde o problema ocorre? quem é afetado?  Cite brevemente a área de aplicação (educação, saúde, transporte, etc.).
		2. **Problema central**:  Explique qual é a dificuldade, limitação ou necessidade que o sistema resolverá.  O problema deve ser formulado de forma clara, por exemplo:  “Atualmente, os tutores de academia têm dificuldade em acompanhar o progresso dos alunos em tempo real...”
		3. **Proposta de solução**:  Apresente o sistema como resposta direta ao problema descrito.  Mostre como o sistema vai resolver ou minimizar o problema. Exemplo:  “Para solucionar esse problema, propõe-se o desenvolvimento de um sistema web que permita aos tutores registrar, atualizar e visualizar o desempenho dos alunos.”
	* Motivação (Apresente Referências).
		1. **Importância do problema**:  Mostre dados, estatísticas ou referências que comprovem a existência e a gravidade do problema.  Exemplo: “Segundo dados do IBGE (2023), cerca de 70% das pequenas empresas não possuem controle automatizado de estoque...”
		2. **Benefícios esperados**:  Explique quem se beneficia com a solução (usuários, empresas, sociedade).
	* Arquitetura Geral do Sistema.
2. Estudo de Viabilidade
	* Web Scraping ou PDF Scraping ou Image Scraping (Obrigatório).
	* Integração com Telegram ou Análise usando IA (Opcional).
3. FastAPI => Back-end + Banco de Dados
	* Salvar os Scrapings no Banco de Dados (Pedir pra eles fazerem)
4. React => Front-end
	* Mostrar os Scrapings no Front-End (Pedir ora eles fazerem)
5. Minimum Viable Product (MVP)
	* É a versão mais simples de um produto de software que contém apenas as funcionalidades essenciais para ser lançada, com o objetivo de testar a ideia no mercado e coletar feedback dos usuários
